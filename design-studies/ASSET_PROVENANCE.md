# Visual study asset provenance

All people and studios depicted are fictional. The photographs are new generated assets supporting the user’s original visual direction, not recovered image layers from the original board.

- `/images/saleane-studio-warm.png`: generated by the parent agent using the built-in image generation tool, then inspected by this visual agent. Cream linens, sunlit travertine and olive branches.
- `/images/saleane-studio-night.png`: generated and inspected by the parent agent using the built-in image generation tool. The After Dark guest expression.
- `assets/fictional-client-portraits.png`: generated and inspected by this visual agent using the built-in image generation tool. Saved from the image tool's output folder. Four fictional photographic head-and-shoulder portraits, displayed through CSS quadrant crops.
- `assets/bodoni-moda.woff2`: unmodified Latin variable font copied from the repository’s installed `@fontsource-variable/bodoni-moda` package, with its OFL licence.
- `assets/source-sans-3.woff2`: unmodified Latin variable font copied from the repository’s installed Fontsource package, with its OFL licence.

Top right: woman with pale skin and blonde shoulder-length hair, about 40, soft neutral clothing. Bottom left: woman with medium brown skin and dark wavy hair, about 30, ivory top. Bottom right: woman with East Asian features and straight dark hair, about 35, neutral clothing. All fictional people, relaxed genuine expressions, front-facing head and shoulders with full heads centred in each square and ample crop space for circular UI avatars. Soft natural window light, refined warm off-white studio background, realistic skin texture, understated editorial beauty photography. All four portraits consistent scale. No text, no logos, no watermark, no icons, no illustrated elements.
