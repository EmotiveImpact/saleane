# SALEANE generated photo library

Created 7 October 2026 with OpenAI's built-in ChatGPT `image_gen` tool. All 40 images are AI-generated candidates, including the people and premises. Existing studio images and client portraits are preserved.

WebP exports use quality 80: wide 2400 × 1600, tall 1600 × 2000, square 1600 × 1600, panorama 2400 × 1030. The explicit size table takes precedence over the general 2400px-width instruction. Exports are resampled from the native generated PNG sizes, which are recorded in the manifest; they are not native 2400px generations.

Original PNGs: `design-studies/photo-originals/<group>/<name>.png`. Prompts, dimensions and checksums: `design-studies/photo-library/manifest.json`. Review all candidates in [the numbered gallery](../../../design-studies/photo-library/GALLERY.md). Select 8 to 12 before applying them to the app skin; all candidates remain available.
