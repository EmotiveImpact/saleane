# House photographs

Twelve photographs chosen by the owner on 7 October 2026 from the generated library in pull request #15 (branch `assets/photo-library-2026-10-07`), where the full set of 40, the original PNGs, prompts and checksums live.

All are AI-generated (OpenAI image generation) and show fictional rooms and details, with no people. They set the mood of the demo and sample studios. They must not be presented as an actual studio's premises or as human-shot photography. A live studio supplies its own authorised photographs.

The paths used by the app are listed in `src/design/photos.tsx`.
